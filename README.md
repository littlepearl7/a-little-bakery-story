# 林记烘焙 · A Little Bakery Story

移动端竖屏经营游戏。36 个月、180 个经营日，从一家社区老店做到连锁品牌。
按 `story/游戏设计方案 V5.md` 的架构重写。

## 怎么跑

### 只是想玩

双击项目根目录的 **`双击开始游戏.bat`**，或者直接双击 `dist/林记烘焙.html`。

存档在浏览器 localStorage 里，自动保存。

### 想改东西

```bash
npm install      # 第一次
npm run dev      # http://127.0.0.1:5180
```

### 重新生成可双击的版本

```bash
npm run build
```

产出三份内容相同的单文件 HTML：`dist/index.html`、`dist/play.html`、`dist/林记烘焙.html`。
构建末尾会自动跑 `tools/make-standalone.mjs` 把 JS/CSS 内联进去，并带语法自检。

## 核心循环

每个经营日四步：

1. **厨房** — 排今天的产量。每款产品有售价档位（亲民 / 标准 / 精品）和预计销量。
2. **店铺** — 接今天的订单，开门营业，结算当天销售。
3. **打烊** — 处理没卖完的（打折 / 留给伙伴 / 社区分享 / 报损），然后进入下一天。

每天恢复 **8 点行动力**（装修可升到 10）和 **70 点体力**（上限 100）。
每月 5 个经营日，第 5 天打烊后做**月末结算**：扣固定成本、出经营报告。

**产能** = 体力 + 妈妈 60 点 + 每位伙伴 40 点。超出免费产能的部分才扣你的体力。

每 6 个月做一次**阶段结算**：完成规定数量的目标才能进入下一章，否则本局直接进入对应的短篇结局。
第 36 个月进入最终结局（社区老店 / 传统老字号 / 创意品牌 / 区域连锁 / 全国连锁）。

## 已实现（V5 的 P0 + 部分 P1/P2）

- 5 个页签：店铺 / 厨房 / 伙伴 / 经营 / 图鉴
- 180 个经营日，行动力 + 体力双资源
- 生产排产、定价三档、自然客流、每日订单、剩货处理
- 12 款产品按月份解锁，各自独立熟练度
- 4 位具名伙伴，按剧情月份加入，各自有信赖度与专业能力
- 经营偏好四维（传统 / 创新 / 效率 / 社区）隐藏计分
- 六个阶段目标 + 五个短篇结局 + 五个最终结局
- 月末经营报告、剧情事件触发、本地存档

## 尚未实现 / 已知简化

对照 V5，以下还没做或做了简化：

- **顾客系统**：只有需求量模型，没有具名常客档案
- **设备系统**：烤箱/搅拌机/冷藏柜等七件设备未实现
- **装饰系统**：只有店铺等级，没有单独购买摆件
- **订单类型**：只有普通/定制/线上/节日四种计数，没有企业团购与纪念日
- **信赖度成长线**：数值有了，但 M11 小本子、M18 可欣的原创方案等专属剧情还没接
- **经营风格解锁**：四维分数在累积，但「≥60 且领先 15 分解锁专属剧情」尚未触发任何内容
- **二周目与云存档**：未实现
- **《转让》结局**：未实现
- 桂花栗子蛋糕目前用「招牌 · 从一块开始」代替，菜单里没有独立条目

## 剧情与系统的错位

台词文件 `story/剧情对话.md` 是按 V3 大纲写的，V5 改了几处：

- M6 是「夏日生活节」，台词写的是生活市集
- M11 应该是「小雨拿出创意小本子」，台词写的是订单排期
- M5 / M13 / M19 / M23 / M27 应为三选一，M33 为四选一，台词目前是两选一
- M20 多了「开分店 / 线上渠道」的分支

这些还没对齐，属于下一步要补的内容。
