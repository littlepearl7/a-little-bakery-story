# 林记烘焙 · A Little Bakery Story

移动端竖屏浏览器小游戏。36 个月，从一家社区老店做到全国连锁。

## 怎么跑

### 只是想玩

双击项目根目录的 **`双击开始游戏.bat`**，或者直接双击 `dist/林记烘焙.html`。

存档写在浏览器 localStorage 里，刷新、关掉再开都还在。因为是 `file://` 打开，换浏览器或清理浏览器数据会丢档。

### 想改东西

```bash
npm install      # 第一次
npm run dev      # 开发预览，http://127.0.0.1:5180
```

改剧情 md、改代码都会热更新，最方便。

### 改完想重新生成可双击的版本

```bash
npm run build
```

会产出三份内容完全相同的单文件 HTML：`dist/index.html`、`dist/play.html`、`dist/林记烘焙.html`。
随便双击哪一个都能玩，也可以丢到任意静态服务器上托管。

> 构建末尾会自动跑 `tools/make-standalone.mjs`，把 JS/CSS 内联进 HTML。
> 不做这一步的话，`file://` 下浏览器会用 CORS 拦截外部模块脚本，双击只会看到白屏。
> 这一步还带语法自检：转义后如果脚本被破坏，构建会直接报错，不会产出一个白屏包。

## 目录

```
story/剧情大纲.md        ← 世界观、人物、36 个月大纲。设定的唯一来源
story/剧情对话.md        ← 游戏里实际播放的台词。改这里会直接改变游戏
story/剧情对话_v1_旧版.md ← 上一版（旧设定），只作留档，游戏不读
src/data.js              ← 蛋糕、城市、装修、行动、角色的静态数据
src/store.js             ← 游戏规则：行动效果、月结算、数值公式
src/story.js             ← 剧情 md 的解析器
src/App.vue              ← 外壳：顶栏、底部导航、结局弹层
src/pages/               ← 六个页面
src/components/          ← 蛋糕插画、剧情弹层
public/art/              ← 从设定集切出来的美术资源
picture/                 ← 原始设定集与蛋糕图（不要删，切图脚本要用）
tools/crop_art.py        ← 切图脚本，改了坐标重新跑
tools/grid_preview.py    ← 给原图打百分比网格，用来量切图坐标
tools/make-standalone.mjs ← 生成可双击的单文件 HTML
素材需求.md               ← 还缺哪些图、给绘图工具的 prompt
```

## 改剧情

分两层：

- **设定**：`story/剧情大纲.md`。改故事、改人物、改月份安排，改这里。
- **台词**：`story/剧情对话.md`。游戏实际播放的内容，格式见该文件最后一节「编辑说明」。

两者靠事件 ID 和月份对应。改完保存，开发服务器会热更新；打包版本刷新页面即可。

如果某一行格式写错了，浏览器控制台会打印 `[剧情] 有 N 行没解析成功` 并指出是哪一行。

## 改数值

- 蛋糕售价/成本/解锁门槛：`src/data.js` 的 `CAKES`
- 城市开店价格与门槛：`src/data.js` 的 `CITIES`
- 装修价格：`src/data.js` 的 `SHOP_LEVELS`
- 收入与支出公式：`src/store.js` 的 `monthlyIncome` / `monthlyExpense` / `estimateSale`
- 结局判定：`src/store.js` 的 `pickEnding`（≥6 家店全国连锁，≥3 家区域品牌，否则温暖小店）

## 已实现

- 36 个月 × 每月 3 点行动力
- 九种经营行动，全部有实际数值反馈
- 12 款蛋糕配方，按烘焙技能顺序解锁
- 门店 4 级装修、8 座城市扩张
- **41 段剧情**：M1–M36 主线（含 M29 高三回忆整段）、7 个选择分支、4 个随机事件
- 友情值、友情相册
- 三种结局，全部为正面结局，没有失败
- localStorage 自动存档，刷新可恢复

## 尚未实现

剧情已按 V3 大纲重写，但经营系统仍是第一版的结构，以下需要第二阶段对齐：

- **员工是计数不是角色**：目前「招聘员工 +1」，V3 要求周雨桐 / 许知遥 / 唐可欣 / 叶清禾四人有独立档案和成长阶段
- **开局不是老店状态**：V3 要求第一天就有成熟产品体系和高口碑，现在是从 1 个配方、6000 元起步
- **结局按门店数判定**：V3 要求按 `endingScore` 综合经营成绩
- 缺少 `storyFlags` / `characterProgress` 状态记录，重要剧情只靠「播放过」标记
- 桂花栗子蛋糕还没有对应的配方条目，剧情里提到但菜单里没有
- 角色表情：只有苏晴和林暖有表情图；新加的四个角色没有头像，显示姓名首字
- 蛋糕图：12 张实拍图已备好但尚未接入，菜单里仍是 SVG 示意图
- 装修场景、音效与 BGM
