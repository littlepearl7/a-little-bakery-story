# 第一章 游戏概述

## 1.1 基本信息

| 项目 | 设定 |
|---|---|
| 游戏名称 | 林记烘焙 |
| 游戏类型 | 模拟经营、剧情养成、休闲收集 |

| 剧情主题 | 成长、亲情、友情、传承、创业 |
| 爱情线 | 不设置 |

## 1.2 核心故事

林念，22岁，刚刚大学毕业。

毕业前，她对未来充满期待，认真准备简历、参加招聘会、投递心仪的公司。

然而现实并不顺利。

简历大多石沉大海，几场面试也没有得到满意的结果。看着身边的同学陆续找到工作，林念逐渐陷入焦虑。

又一次收到拒信后，她彻底破防。

林念：大学四年，毕业即失业。我到底在干什么啊……

无奈之下，她决定先回家。

母亲林暖经营着一家名为「林记烘焙」的老店，已经有三十多年的历史。店铺最初由外婆创立，后来交给林暖经营。

林念从小在店里长大，耳濡目染，早已掌握不错的烘焙手艺。

林暖看到女儿最近一直为求职发愁，便提出：

林暖：既然一时半会儿找不到心仪的工作，不如先回来帮帮我？

林念：妈，我又不是学烘焙专业的。

林暖：你从小就在这里做蛋糕，手艺可不比别人差。再说了，我也没说让你一辈子待在这里。

林暖：店里的事情，你其实也熟悉不少。从今天开始，日常经营交给你试试，我在旁边帮你把关。

林念：啊？这么突然？

林暖：怎么，不敢？

林念：谁说的！

就这样，林念正式接手林记烘焙的日常经营。

最初，她只是打算暂时帮忙，没想到这次回来，会彻底改变自己未来三年的生活。

## 1.3 游戏的核心体验

玩家将经历四个阶段：

**第一阶段：经营一家店。**

亲自制作蛋糕、接待顾客、管理原料、研发新品、升级设备。

**第二阶段：培养一群人。**

招聘员工，了解他们的故事，培养专业能力，逐渐学会分工。

**第三阶段：建立自己的品牌。**

开设分店、统一产品品质、建立品牌形象、拓展线上业务。

**第四阶段：实现自己的经营理想。**

根据经营风格和玩家选择，走向社区老店、传统老字号、创意烘焙品牌、区域连锁或全国连锁。

游戏不强制所有人走向全国扩张。

经营好一家店，也是一种完整的人生选择。

# 第二章 世界观与人物设定

## 2.1 林记烘焙的背景

林记烘焙是一家经营三十多年的社区老店。

它并不是一家等待拯救的濒临倒闭店铺，而是一家拥有稳定客源和良好口碑的老字号。

主要特点：

- 很多街坊从年轻时就开始光顾林记。
- 有些老顾客已经连续十几年在这里订购生日蛋糕。
- 很多家庭会提前预订除夕团圆蛋糕。
- 林暖拥有成熟稳定的经典配方。
- 店铺在当地拥有很好的口碑。
- 许多顾客是看着林念长大的。

游戏前期的经营目标不是拯救店铺，而是让老店焕发新的活力。

# 第三章 核心经营系统

## 3.1 游戏时间结构

游戏共36个月，分为六个章节，每章六个月。

每个月包含5个代表性经营日。

总计：

- 36个月。
- 180个经营日。
- 6个阶段结算。
- 多条经营和人物剧情分支。

这里的5个经营日是游戏中的代表性经营回合，并不要求模拟真实的每一天。

每个经营日都可以进行完整经营，完成后进入下一回合。

每个月最后一个经营日进行月度结算。

## 3.2 每日经营流程

每个经营日分为六个步骤：

1. **查看今日情况：** 查看天气、节日、订单、库存和顾客需求。
2. **经营安排：** 选择菜单、定价、生产数量和员工分工。
3. **使用行动力：** 采购、研发、宣传、培训、交流等。
4. **蛋糕制作：** 林念和员工完成生产。
5. **正式营业：** 顾客自动进店，系统结算销售。
6. **打烊结算：** 查看收入、剩余产品、顾客评价和经验增长。

每天都能获得一些经营收益或成长反馈。

玩家不需要等待现实时间，也不需要每天登录才能恢复资源。

---

## 3.3 行动力系统

<badge color="success">每日资源\</badge>

行动力用于经营管理、研发、交流和其他非生产活动。

初始行动力8点，后期最多升级至10点。

每日经营开始时恢复满值，不累积。

| 行动 | 消耗 |
|---|---|
| 与伙伴深入交流 | 1 |
| 原料采购 | 1 |
| 顾客反馈处理 | 1 |
| 员工培训 | 2 |
| 新品研发 | 2 |
| 市场宣传 | 2 |
| 产品调研 | 2 |
| 店铺装修 | 2—4 |
| 外出考察 | 2 |
| 分店筹备 | 3 |

以下操作不消耗行动力：

- 查看经营数据。
- 查看员工状态。
- 查看产品图鉴。
- 调整已解锁菜单。
- 设置员工日常岗位。
- 查看剧情记录。
- 查看库存和销量。

这样可以让行动力真正用于重要决策，而不是限制玩家查看信息。

## 3.4 体力系统

体力主要用于林念亲自参与生产。

初始上限100点。

每个新的经营日恢复70点，上限不超过100点。每个月结束后额外恢复至满值。

| 工作 | 体力消耗 |
|---|---|
| 简单蛋糕制作 | 8 |
| 普通奶油蛋糕 | 12 |
| 复杂蛋糕 | 18 |
| 定制蛋糕 | 22 |
| 批量准备原料 | 10 |
| 新品试制 | 15 |

体力不足时：

- 可以让母亲或员工协助制作。
- 可以减少当天制作数量。
- 可以优先制作利润较高的产品。
- 可以选择休息。

不允许因为体力不足导致游戏无法继续。

## 3.5 资金系统

初始资金建议设定为12,000游戏币。

资金主要用于：

- 原料采购。
- 设备升级。
- 店铺装修。
- 员工工资。
- 宣传活动。
- 新门店筹备。

林记为家族经营的店铺，不需要承担高额租金。

每个月统一结算水电、原料损耗和其他固定成本。

资金不足时可以：

- 减少装饰购买。
- 暂缓非必要设备升级。
- 优先生产高利润产品。
- 接取定制订单。
- 使用一次母亲提供的周转支持。

普通经营失误不允许直接导致破产。

可以设置资金管理分数，但不要让玩家陷入无法翻身的负循环。

# 第四章 蛋糕制作与销售系统

## 4.1 产品体系

初始产品只有三款：

1. 原味奶油蛋糕。
2. 草莓奶油蛋糕。
3. 巧克力蛋糕。

随着剧情和经营发展逐渐解锁其他产品。

| 解锁时间 | 产品 | 文件名 |
|---|---|---|
| M1 | 原味奶油蛋糕 | cake-plain |
| M1 | 草莓奶油蛋糕 | cake-strawberry |
| M1 | 巧克力蛋糕 | cake-chocolate |
| M3 | 芋泥薄脆 | cake-taro |
| M4 | 抹茶蛋糕 | cake-matcha |
| M6 | 芒果慕斯 | cake-mango |
| M8 | 提拉米苏 | cake-tiramisu |
| M10 | 无花果奶油 | cake-fig |
| M12 | 季节水果蛋糕 | cake-seasonal |
| M16 | 生日定制蛋糕 | cake-custom |
| M20 | 节日限定蛋糕 | cake-festival |
| M26 | 招牌蛋糕 | cake-signature |

每款蛋糕需要有独立的图片、配方、成本、售价、熟练度和顾客评价。

## 4.2 制作流程

玩家选择当天菜单后，安排生产数量。

每款产品有：

- 制作成本。
- 参考售价。
- 制作难度。
- 产品品质。
- 预计销量。
- 保鲜时间。

玩家可以根据预计销量安排制作。

例如：

今日预计销量：

- 原味奶油蛋糕：5份。
- 草莓奶油蛋糕：8份。
- 巧克力蛋糕：4份。

玩家可以按照预测安排数量，也可以主动增加或减少。

不要求每次都精确命中销量。

## 4.3 产品熟练度

每款蛋糕有独立熟练度。

| 等级 | 效果 |
|---|---|
| Lv1 | 基础制作 |
| Lv2 | 品质提升 |
| Lv3 | 制作效率提升 |
| Lv4 | 解锁特殊装饰 |
| Lv5 | 解锁专属制作效果 |

制作、研发、培训都可以提高熟练度。

## 4.4 定价策略

每款产品提供三种定价方式：

- 亲民定价：销量较高，利润较低。
- 标准定价：销量和利润较平衡。
- 精品定价：利润较高，但顾客对品质要求更高。

定价可以随时调整，不需要每天反复设置。

## 4.5 顾客系统

顾客分为：

- 普通顾客。
- 熟客。
- 定制顾客。
- 节日顾客。
- 特殊剧情顾客。

熟客拥有独立偏好。

顾客满意度提高后，会增加复购概率和推荐概率。

部分顾客会解锁个人故事和特殊订单。

## 4.6 订单系统

订单类型：

- 普通购买。
- 生日定制。
- 婚礼甜品台。
- 节日订单。
- 企业团购。
- 特殊纪念日订单。

每笔订单有产品要求、交付时间和奖励。

订单可以提前沟通调整一次，不设置极端苛刻的时限。

完成后获得资金、口碑、顾客忠诚度和经验。

## 4.7 剩余产品处理

每天打烊后，未售出的蛋糕可以：

- 打折出售。
- 作为员工福利。
- 参与社区分享活动。
- 报损处理。

不同方式影响利润和社区温暖度。

# 第六章 经营风格与分支路线

游戏设置四种主要经营偏好。

它们不是互斥职业，而是玩家在长期经营中形成的品牌特色。

## 6.1 传统手作派

核心理念：保留林记的传统味道。

主要行为：

- 保留经典配方。
- 研发传统风味蛋糕。
- 重视老顾客。
- 保留手工制作特色。
- 传承外婆的配方。

解锁：

- 外婆的旧配方。
- 林暖年轻时的经营故事。
- 传统节日礼盒。
- 老顾客回忆。

代表产品：桂花栗子蛋糕、传统奶油蛋糕。

最终方向：传统手作老字号。

## 6.2 创意新品派

核心理念：不断尝试新的口味和设计。

主要行为：

- 新品研发。
- 季节限定。
- 创意装饰。
- 食材搭配。
- 参加烘焙活动。

解锁：

# 第七章 人物培养与信赖度系统

这是游戏的重要长期养成内容。

每位主要伙伴都具有两个独立属性：

**信赖度：** 角色对林念的信任程度。

**专业能力：** 角色在自己岗位上的成长程度。

信赖度不能代替专业能力，专业能力也不能代替信赖度。

## 7.1 信赖度等级

数值范围0—100。

| 数值 | 阶段 | 内容 |
|---|---|---|
| 0—29 | 初步认识 | 普通工作对话 |
| 30—49 | 熟悉伙伴 | 日常生活剧情 |
| 50—69 | 逐渐信任 | 个人经历 |
| 70—84 | 亲密伙伴 | 关键个人剧情 |
| 85—100 | 深度信赖 | 隐藏剧情和特殊帮助 |

信赖度主要通过：

- 重要剧情选择。
- 处理角色提出的问题。
- 支持角色个人目标。
- 兑现承诺。
- 合理安排工作。

获得。

日常交流可以少量增加信赖度，但不允许通过无限重复点击聊天刷满。

## 7.2 周雨桐个人成长线

**核心问题：她不是没有学习机会，而是不敢相信自己的想法值得被认可。**

### M8：加入林记

小雨以兼职学徒身份加入。

负责水果处理、原料准备、包装和简单制作。

玩家可以选择耐心指导、鼓励尝试或严格要求。

不同选择影响信赖度和后续对话。

### M11—M13：藏起来的小本子

触发条件：

- 信赖度达到60。
- 完成至少两次员工互动。

某天打烊后，小雨拿出一本旧本子。

里面记录着许多蛋糕草图和水果、奶油、夹心的搭配想法。

林念发现她其实一直在独立研究新品。

小雨：我有时候会想一些蛋糕的搭配，但是一直没有机会真正做出来。

林念：为什么不试试？

小雨：我怕做得不好。

林念：那就先做一小批，慢慢调整嘛。

**玩家选择：**

A. 支持她独立完成一次新品试制。

- 信赖度+15。
- 专业能力+10。

B. 与她一起研究配方。

- 信赖度+12。
- 专业能力+8。

C. 鼓励她先整理思路，再安排试制。

- 信赖度+8。
- 专业能力+5。

最终，小雨完成自己的第一款创意水果蛋糕。

这款产品可以正式加入菜单。

解锁：

- 小雨的个人相册。
- 小雨专属蛋糕。
- 新品研发能力。

### M15—M18：小雨的想法

小雨逐渐向林念敞开心扉。

她原本只希望找一份稳定的工作，但现在开始认真考虑将烘焙作为自己的长期事业。

林念鼓励她继续尝试，不必急于证明自己。

### M27—M29：主动帮助林念

桂花栗子蛋糕研发遇到问题。

小雨发现不同批次栗子的甜度和水分存在差异，主动提出原料分级和小样测试的建议。

她从一个需要别人指导的学徒，成长为能够主动发现问题、提出解决方案的烘焙师。

如果之前触发了高好感剧情，会出现专属对话。

**最终成长：**

- 高信赖、高专业：主力研发烘焙师，拥有自己的招牌产品。
- 高信赖、普通专业：稳定的主力烘焙师。
- 普通信赖、高专业：独立制作能力较强的烘焙师。
- 普通信赖、普通专业：认真负责的正式员工。

任何情况下，小雨都不会因为一次选择而突然离开林记。

## 7.3 许知遥个人成长线

核心问题：擅长沟通，但缺乏管理信心。

M14加入后负责前台和订单。

M16逐渐接触复杂订单。

M19提出建立更规范的订单管理系统。

如果信赖度达到60，解锁她的个人经历：她一直希望能够独立负责一家门店。

M27如果信赖度达到70且完成管理系统剧情，她会主动协调订单和顾客沟通。

最终成长为门店店长或区域运营负责人。

## 7.4 唐可欣个人成长线

核心问题：过于追求标准化，曾经逐渐失去研发新品的热情。

M18加入，负责配方标准化和生产管理。

初期与林念在产品理念上产生分歧。

高信赖度后，可欣会透露自己过去曾有一款原创蛋糕方案，但因为公司经营要求没有机会推出。

玩家支持她重新研发。

M27由她负责桂花栗子蛋糕的生产流程优化。

最终成长为研发负责人。

## 7.5 叶清禾个人成长线

核心问题：创意丰富，但不擅长商业设计。

M21—23开始长期合作。

高信赖度后，清禾会邀请林念帮忙准备个人作品展示。

玩家可以选择帮助她整理作品、拍摄产品照片、提供商业反馈。

M33旗舰店设计时，她会拿出一套完整的品牌视觉方案。

最终成为品牌设计师，同时拥有自己的独立事业。

## 7.6 林暖家庭默契线

设置独立的家庭默契值。

通过日常互动、经营选择和配方剧情提升。

逐渐解锁：

- 林暖年轻时经营林记的故事。
- 外婆留下的旧配方。
- 林暖与外婆的回忆。
- 林暖逐渐交接经营权的过程。

高默契结局：林暖放心将林记交给女儿，自己偶尔回店里帮忙。

# 第八章 林念与苏晴的友情主线

这是游戏最重要的人物关系之一。

苏晴从游戏开始就是林念的好朋友，不存在重新认识、重新联系的剧情。

友情线不使用普通员工好感度，也不设置BE。

## 8.1 高一：成为真正的朋友

高一时，林念和苏晴同班同桌。

两人逐渐成为朋友。

某次班级活动需要制作海报，林念觉得苏晴画画很好，没有提前询问就替她答应了下来。

苏晴对此有些不高兴。

放学后，她直接告诉林念：

苏晴：我不是不想帮忙，但你以后能不能先问问我？

林念：啊？我以为你会喜欢。

苏晴：你可以觉得我适合，但不要直接替我做决定。

林念：好像确实是我没考虑到。

苏晴：我知道你没有恶意，所以我才直接告诉你。

林念：那以后我们有什么不舒服的地方，都直接说出来吧。

苏晴：嗯？

林念：我觉得朋友之间就应该这样。小问题一直憋着，最后可能就变成大问题了。

苏晴：那你也要接受我直接说你哦。

林念：当然！

旁白（林念视角）：

那天之后，我觉得苏晴是一个很特别的人。

她不会因为怕我不高兴，就把自己的想法藏起来。

我突然觉得，能遇到一个愿意认真和自己沟通的人，是一件很幸运的事情。

**林念从这时开始，希望和苏晴做一辈子的好朋友。**

## 8.2 高二：隔壁班的好朋友

选科分班后，两人去了隔壁班。

日常剧情：

- 下课串班聊天。
- 一起去食堂。
- 分享零食。
- 交换试卷。
- 讨论小说。
- 互相吐槽考试。
- 放学约着回家。

两人逐渐形成一个固定习惯：

「下课来找我。」

## 8.3 高三：苏晴认定一辈子的朋友

高三时，苏晴换了一位新同桌沈妍。

沈妍曾有双相情感障碍的诊疗经历。苏晴此前听过同学的提醒，但并不了解她的具体情况，也没有因为诊断就认定对方会伤害别人。

某节晚自习下课，林念照常来苏晴班上聊天。

林念：我给你带了妈妈做的小面包！

苏晴：哇！谢谢你！

苏晴咬了一口。

苏晴：真好吃！

两人聊着天，沈妍突然从教室前门冲进来，情绪激动，手里拿着一把长柄伞，朝苏晴挥动。

苏晴完全没有反应过来。

林念第一时间冲上前，试图将两人分开，同时大声呼喊老师。

周围同学被突发情况吓住，班长赶紧跑去通知值班老师。

短暂的混乱后，老师赶到现场，制止了冲突。

学校联系了相关家长，安排后续处理，并为苏晴调整座位，保障她的安全。

剧情不将心理疾病与暴力行为简单画等号，重点呈现事件给当事人带来的惊吓，以及朋友之间的支持。

事情发生后，苏晴被老师叫去询问经过。

她一直表现得很冷静，能够清楚地回答老师的问题。

直到她走出办公室。

她看到了刚从办公室回来的林念。

林念的眼睛红红的。

一见到苏晴，她就走上前，紧紧抱住了她。

林念：你吓死我了……

林念：有没有哪里不舒服？

苏晴已经记不清林念具体说了什么。

她只记得那个拥抱。

刚刚还能冷静回答老师问题的她，在看到林念的那一刻，突然忍不住了。

那些被压下去的惊吓和委屈一下子涌了上来。

她抱着林念哭了出来。

旁白（苏晴视角）：

刚刚在教室里的时候，我好像什么感觉都没有。

老师问我事情经过，我可以很平静地回答。

可是看到林念的那一刻，我突然就忍不住了。

我想起高一的时候，我们约定过，有什么事情都要直接告诉对方。

我也想起高二的时候，每次一下课，她总会出现在我们班后门。

原来有一个人会这样在意自己，是一件很幸福的事情。

**苏晴想：我想和这个人做一辈子的好朋友。**

## 8.4 大学：异地但不疏远

两人大学在不同城市。

但一直保持联系。

- 分享大学生活。
- 视频聊天。
- 互相倾诉烦恼。
- 寒暑假约见面。
- 讨论毕业后的规划。

苏晴逐渐喜欢上摄影，开始培养自己的职业方向。

林念则继续学习自己的专业知识，同时保留对烘焙的兴趣。

## 8.5 毕业后三年：友情与成长

苏晴回到栖云镇发展。

她从游戏开始就知道林念回家接手林记的事情。

两人保持着高中以来的相处习惯。

重要剧情：

- M1：苏晴来店里，调侃林念成为林老板。
- M4：一起吃饭，聊大学生活。
- M6：苏晴帮助林记拍摄宣传照片。
- M9：林念为苏晴制作生日蛋糕。
- M15：苏晴分享自己的摄影作品。
- M23：两人因为临时取消约定产生小矛盾，直接沟通解决。
- M24：苏晴送给林念一组林记成长照片。
- M27—29：苏晴帮助林念解决桂花栗子蛋糕危机。
- M33：苏晴拍摄旗舰店。
- M35：整理三年相册。
- M36：三周年合影。

## 8.6 友情互动规则

玩家可以选择：

- 主动分享烦恼。
- 认真听苏晴讲工作。
- 邀请苏晴吃饭。
- 支持她的摄影项目。
- 直接表达自己的不满。

选择会影响对话、回忆和相册解锁。

**任何选项都不会造成两人绝交、友情消失或友情BE。**

友情相册记录两人的重要时刻，不需要全部收集才能完成主线。

# 第十章 阶段目标与短线结局

**这是游戏最重要的进度控制系统。**

每六个月进行一次阶段结算。

达成目标，进入下一阶段。

未达成目标，直接播放对应的短线结局，结束本轮游戏。

不允许延后目标，不允许无限重复刷取。

但短线结局不是坏结局。

## 10.1 第一阶段：M1—M6

主题：从毕业生到经营者。

三项目标完成两项即可：

1. 社区口碑达到25。
2. 解锁至少2款新品。
3. 完成至少2笔定制订单。

达标：

解锁LV2店铺、更多产品展示位和下一阶段经营内容。

未达标结局：

### 《街角的灯》

林念发现自己其实很喜欢现在的生活。

虽然没有做出惊人的成绩，但熟悉的顾客依然每天来买蛋糕。

林暖看着忙碌的女儿，觉得她已经成长了不少。

苏晴偶尔来店里，坐在窗边陪林念聊天。

林念决定不再急着追求宏大的目标，先把眼前的小店经营好。

**一家小店，一种喜欢的生活。**

## 10.2 第二阶段：M7—M12

四项目标完成两项：

1. 店铺升级至LV2。
2. 累计完成8笔线上订单。
3. 研发至少3款新品。
4. 完成年度节日订单目标。

达标：

解锁更多产品展示位、线上推广和品牌包装升级。

未达标结局：

### 《熟悉的味道》

一年过去，林记依然是栖云镇那家熟悉的老店。

除夕夜，店里摆满了提前预订的蛋糕。

陈奶奶笑着说：

陈奶奶：还是你们家的蛋糕好吃，这么多年都没变。

林念看着忙碌的母亲和熟悉的顾客，觉得这样也很好。

**没有成为大品牌，但林记依然是大家熟悉的林记。**

## 10.3 第三阶段：M13—M18

四项目标完成两项：

1. 产品平均品质达到3级。
2. 完成至少3款标准化配方。
3. 店铺口碑达到45。
4. 至少一名员工专业能力达到3级。

达标：

解锁分店筹备。

未达标结局：

### 《小小的团队》

林念发现，经营一家店已经占据了自己大部分精力。

她决定暂时放弃扩张，继续和伙伴们经营好栖云镇的林记。

大家每天一起工作、研发新品、分享生活。

林念也第一次明白，经营事业不一定要不断扩大规模。

**有一群可靠的伙伴，有一家喜欢的店，就已经很好。**

## 10.4 第四阶段：M19—M24

四项目标完成两项，其中至少一项必须是业务扩张目标：

1. 成功开设第一家分店。
2. 建立稳定的线上或商业合作渠道。
3. 建立统一库存系统。
4. 至少两名伙伴信赖度达到50。

达标：

解锁区域品牌发展。

未达标结局：

### 《栖云镇的招牌》

林记逐渐成为栖云镇非常有名的烘焙店。

林念尝试过扩张，但最终发现自己更喜欢现在的经营方式。

她将店铺重新装修，增加了更多座位，也让团队拥有更舒适的工作环境。

苏晴拍下店铺最漂亮的照片。

林念：其实我们也没有走得很远嘛。

苏晴：但是你已经把这里变成自己喜欢的样子了呀。

**没有走向全国，却成为一座小城里不可替代的存在。**

## 10.5 第五阶段：M25—M30

四项目标完成两项：

1. 成功研发桂花栗子蛋糕。
2. 完成生产和运输测试。
3. 完成秋日文化节。
4. 至少两位伙伴提供专属协助。

无论经营水平如何，都先播放林念和苏晴的友情高潮剧情。

达标：

进入最后阶段。

未达标结局：

### 《桂香留在栖云》

秋日文化节结束后，林记的桂花栗子蛋糕获得当地顾客的喜爱。

林念发现团队目前还不适合大规模扩张。

她决定将这款蛋糕作为林记的秋季限定产品，每年秋天都会推出。

苏晴将这段时间拍摄的照片整理成册。

林念和伙伴们一起坐在店里，吃着最后一批桂花栗子蛋糕。

**有些味道，不需要传遍全国，也值得一直保留下去。**

## 10.6 第六阶段：M31—M36

不设置普通失败结局。

根据玩家的经营成绩、经营偏好和人物培养情况，进入最终结局。

# 第十一章 剧情选择与数值分支

玩家的重要选择会影响经营数值、角色信赖度和后续剧情。

## 11.1 M5：第一笔大型订单

顾客需要一款特殊生日蛋糕。

A. 采用传统奶油装饰。

- 传统偏好+5。
- 解锁传统产品路线。

B. 尝试新的装饰方式。

- 创新偏好+5。
- 获得新品研发经验。

C. 先询问顾客具体喜好。

- 社区偏好+5。
- 顾客忠诚度增加。

## 11.2 M13：产品标准化

A. 坚持手工制作。

传统偏好增加，产品特色更强。

B. 引入统一制作流程。

效率偏好增加，后续更容易发展多门店。

C. 保留核心手工步骤，其他流程标准化。

获得平衡路线奖励。

## 11.3 M19：分店筹备

A. 立即筹备实体分店。

投入较大，扩张速度快。

B. 先发展线上销售。

投入较低，解锁线上品牌路线。

C. 与其他店铺合作。

解锁商业合作路线。

## 11.4 M23：与苏晴的小矛盾

A. 认真解释并道歉。

B. 承认最近确实有些忽略朋友。

C. 主动约定以后提前安排时间。

三种选择都能解决矛盾，只是对话不同。

友情不产生BE。

## 11.5 M27：新品危机

A. 坚持原计划，大规模生产。

资金压力较大，需要较强团队能力。

B. 缩减预售数量，优先保证品质。

风险较低，但活动收益减少。

C. 延后部分订单，重新优化配方。

获得额外研发时间。

## 11.6 M33：旗舰店设计

A. 传统复古风格。

B. 现代简约风格。

C. 高端主题风格。

D. 自然温馨风格。

不同选择影响旗舰店最终外观、顾客偏好和结局画面。

# 第十三章 最终结局设计

最终结局由三个维度共同决定：

1. 经营规模和经营成绩。
2. 长期经营偏好。
3. 伙伴个人成长。

友情线不作为失败条件。

## 13.1 社区老店结局

经营规模较小，社区偏好较高。

林念决定继续经营栖云镇的林记。

店铺规模不大，但拥有很高的顾客忠诚度。

## 13.2 传统手作老字号

传统偏好较高。

林记保留外婆的经典配方，形成独特的传统烘焙文化。

桂花栗子蛋糕成为代表产品。

## 13.3 创意烘焙品牌

创新偏好较高。

林记以新品研发、季节限定和创意设计出名。

吸引大量年轻顾客。

## 13.4 区域连锁品牌

经营成绩达到中高水平。

林记在多个城市开设门店，形成成熟的团队和稳定供应链。

## 13.5 全国连锁品牌

经营成绩达到最高水平。

林记建立完整的研发、生产、供应链和运营体系。

高端主题旗舰店正式开业，品牌在多个城市形成连锁布局。

## 13.6 可选遗憾结局：《转让》

这是独立的选择型经营结局，不是阶段目标未达标自动触发。

在后期，玩家可能收到品牌收购邀请。

选择接受后：

林记品牌继续存在，但不再由林念独立经营。

林念暂时离开管理岗位，重新思考未来。

苏晴依然陪伴在她身边。

这是经营道路上的遗憾，不涉及友情破裂。

## 13.7 伙伴个人结局

根据人物信赖度和专业能力展示不同的成长结果。

- 小雨：主力烘焙师、创意产品研发。
- 知遥：门店店长、区域运营负责人。
- 可欣：研发负责人、生产培训负责人。
- 清禾：品牌设计师、独立工作室经营者。
- 林暖：逐渐退居幕后，享受生活。

伙伴个人结局作为最终结局的额外展示，不要求所有人都达到最高信赖度。

# 第十六章 提高长期可玩性的设计

游戏需要让玩家一直有值得期待的内容。

建议重点使用以下机制。

## 16.1 可视化成长

每次升级都能看到店铺明显变化。

不要只让数字增长。

## 16.2 产品收集

持续解锁新蛋糕、新配方、新装饰。

每款蛋糕都需要精美的独立图片。

## 16.3 员工培养

培养角色后，不只是数值变高，还能解锁隐藏剧情和特殊经营帮助。

## 16.4 顾客关系

老顾客会记住林记的变化，也会在重要节点出现。

## 16.5 月度经营报告

每个月结束后展示：

- 收入和支出。
- 最受欢迎产品。
- 本月新品。
- 顾客评价。
- 员工成长。
- 剧情记录。
- 下月目标。

## 16.6 阶段纪念册

每六个月自动生成一张成长记录。

例如：

- 第一次接手林记。
- 第一次新品研发。
- 第一位员工加入。
- 第一次分店开业。
- 桂花栗子蛋糕。
- 全国旗舰店。

## 16.7 二周目玩法

短线结局和最终结局结束后，玩家可以选择重新开始。

保留：

- 已解锁的图鉴。
- 已获得的相册。
- 已收集的特殊装饰。
- 已完成的结局记录。

可以选择从某个已经打完的章节开始继续

设置可以存档，包括云存档

二周目可以获得少量开局便利，但不能直接跳过经营过程。

# 第十七章 游戏平衡原则

1. 不设置现实时间等待。
2. 不设置必须每天登录的任务。
3. 不允许体力或行动力归零导致卡关。
4. 不允许普通经营失误导致破产。
5. 阶段目标采用多项任务完成一定数量的方式。
6. 经营目标和人物好感度目标分开计算。
7. 人物信赖度可以通过多个途径提升。
8. 隐藏剧情不影响主线基本通关。
9. 友情线没有BE。
10. 未达到阶段目标直接进入短线结局，不延后。
11. 短线结局必须有完整的剧情收束。
12. 不同经营偏好都应该有合理的发展路线。
13. 全国连锁不是唯一正确答案。
14. 不使用无意义的重复点击制造游戏时长。
15. 玩家应该始终知道当前目标和下一步可以做什么。

- `choiceFlags`
- `friendshipMemories`
- `endingScore`
- `endingType`

## 18.2 剧情事件格式

每个剧情事件必须包含：

- 唯一事件ID。
- 触发月份。
- 触发条件。
- 前置事件。
- 人物信赖度要求。
- 玩家选项。
- 数值变化。
- 后续分支。
- 是否允许重复触发。

重要剧情采用固定事件，不允许随机跳过。

日常剧情可以按权重随机触发。

## 18.3 阶段结算机制

每六个月进行一次检查。

伪代码：

```javascript
function checkChapterEnding(chapter) {
  const completedGoals = chapter.goals.filter(
    goal => goal.completed
  ).length;

  if (completedGoals >= chapter.requiredGoals) {
    return "NEXT_CHAPTER";
  }

  return chapter.shortEnding;
}
```

阶段结算必须在播放结局前检查所有固定剧情是否已经完成。

特别是第五章：

- 必须完成桂花栗子蛋糕主线。
- 必须播放林念与苏晴的友情高潮。
- 然后才进行阶段目标结算。

## 18.4 存档机制

每个经营日结束自动保存。

# 第十九章 最终设计目标

《林记烘焙》希望让玩家真正拥有一家属于自己的蛋糕店。

最开始，玩家只有三款蛋糕、一个玻璃展示柜，以及林念和林暖两个人。

每天需要考虑做多少蛋糕、卖什么产品、怎么安排原料。

后来，小雨加入了。

她第一次独立完成自己的蛋糕时，玩家会看到她的成长。

再后来，知遥和可欣加入，林记开始拥有真正的团队。

玩家可以升级店铺、研发新品、培养员工、开设分店，也可以选择继续经营一家温馨的小店。

而苏晴始终是林念生活中那个熟悉的人。

她会来店里聊天，会帮忙拍照，会在林念遇到困难时提供帮助。

她们一起经历过高中、大学和毕业后的生活，也会一起见证林记的成长。

三年之后，林记可能成为全国知名的烘焙品牌，也可能成为栖云镇最受欢迎的社区老店。

无论哪一种，林念都已经找到了自己喜欢的生活。

**游戏最终想表达的是：**

有些人毕业后并没有马上找到自己想要的方向，但这不意味着人生就此停滞。

有些事业最初只是一个临时的选择，后来却成为真正热爱的事情。

有些味道，经过很多年依然不会忘记。

有些朋友，走过很远的路，依然会陪在身边。

从林记的一块小小蛋糕开始，慢慢把生活经营成自己喜欢的样子。

**这就是《林记烘焙》。**
